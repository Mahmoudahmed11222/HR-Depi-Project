# HR-Depi-Project

## Project Idea
Human Resources Dataset Analysis — تحليل داتا الموارد البشرية لـ 1470 موظف و6709 تقييم أداء بهدف دراسة معدل دوران الموظفين (Attrition)، الرضا الوظيفي، والعوامل المؤثرة على أداء الشركة.
